# Shop Inventory and Billing Management System

## About the Project

This project is developed using C++ and a Singly Linked List. It helps manage shop products and customer billing operations.

## Features

* Add new products
* Display all products
* Search products by ID
* Update product stock
* Generate customer bills
* Automatically update stock after sales

## Technologies Used

* Programming Language: C++
* Data Structure: Singly Linked List
* Concepts: Structures, Pointers, Dynamic Memory Allocation and Functions

## How to Run

1. Download the `main.cpp` file.
2. Open an online C++ compiler such as OnlineGDB.
3. Paste the code into the editor.
4. Select C++ as the programming language.
5. Click Run.

## Limitations

The current version stores product information in memory. Product records are not saved permanently after the program exits.
